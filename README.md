# Smok for Android

**Where to smoke in Japan.** A map of smoking rooms and open smoking areas at stations, airports and shopping malls, municipal smoking spots and cafes, in 13 languages. Free, no ads, no in-app purchases.

This repository holds the **release builds** of the Android app, for people who install outside Google Play or follow updates with [Obtainium](https://github.com/ImranR98/Obtainium). The app itself is closed source; there is no source code here.

## Download

Go to **[Releases](https://github.com/smoktomap/smok-android/releases)** and download the `.apk` of the latest version.

- Package name: `to.smok.app`
- The file is the same build that is on Google Play, signed by Google Play app signing, so it installs over a Play copy of the same app without losing data.
- Needs Android 8.0 or newer. Works on phones without Google Play services.

## Install

1. Open the downloaded `.apk` on the phone.
2. If Android asks, allow installing from the app you opened it with (your browser or file manager). You can turn that off again afterwards.
3. Open Smok. The map works without an account.

## Follow updates with Obtainium

In Obtainium choose **Add App** and paste `https://github.com/smoktomap/smok-android`. Obtainium will offer every new release from here.
